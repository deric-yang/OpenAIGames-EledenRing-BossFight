# Bundled UI fonts

- CormorantGaramond.ttf: Google Fonts / Cormorant Project, SIL OFL 1.1. Source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- WeepingDunesSerifSC.ttf: renamed subset of Noto Serif SC, SIL OFL 1.1. Source: https://github.com/google/fonts/tree/main/ofl/notoserifsc
- Full upstream license texts are included beside the fonts.
- Chinese subset covers current game and preview labels. Add glyphs when adding new localized text. Original font is in ignored tools/cache, subset generated using fonttools pyftsubset.
