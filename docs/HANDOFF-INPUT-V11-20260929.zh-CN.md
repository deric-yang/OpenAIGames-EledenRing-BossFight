## 已实装

1. 轻击、重击、翻滚共用单个待执行意图，200ms 后过期。已排队的翻滚不会被后续轻击或重击覆盖。
2. 从真实按键事件接收指令，双方顿帧时继续接收，缓冲倒计时暂停；执行时重新检查状态和耐力，仅消耗一次。
3. 采用实验 D 的逐动作接招、翻滚、移动取消窗口，不能提前截掉该招最后一个伤害判定。
4. 翻滚中不能重新开始翻滚刷新无敌帧。击飞期间不能起身；落地后保留新按翻滚起身。
5. 受击、失焦、重置、处决、死亡、胜利、过场会清理旧指令及连段记忆。不会把很久前的攻击带到恢复之后执行。

## 第三段难触发的原因和修复

原实验仅在“当前仍处于轻击动作”时递增 combo。第二段自然结束，或按着移动在 0.49s 收招之后，下一次轻击直接从第一段开始。即便玩家只比动画结束晚按几十毫秒，也会断段。

现保留 **收招后 200ms 的连段衔接期**，适用于第一、第二段自然结束和移动收招。期间新按轻击可继续到下一段；过期后回到第一段。翻滚、重击、受击等会清理这段记忆。第三段结束开启下一轮第一段，不会循环第三段。预输入有效期仍是用户选定的 200ms，没有偷偷延长。

连续过快地按三次并不意味着预排三刀：本设计仍只有一个缓冲槽。发生在第二段允许接招之前太早的输入会过期，这与已确认方案一致。
