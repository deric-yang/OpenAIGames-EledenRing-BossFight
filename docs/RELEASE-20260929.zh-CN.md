## 音效审阅边界

V12.2 独立看板有 26 个动作、64 个新候选和 22 个旧素材对照。其 ElevenLabs SFX V2 请求、裁空白、电平测量、分层实时混音与 A/B/C 审阅管线已可用，但新素材尚未获用户裁定。本轮不搬入独立 `game-source/`，不替换正式战斗 SFX，也不恢复脚步声音。

台词管线与正式/候选声音的详细边界见 [Victor 交接](HANDOFF-VICTOR-VOICE-20260929.zh-CN.md)。本地试听目录为 `experiments/gilded-ruin-audio-v12-20260929`（相对 Gamebench 工作区），不属于此独立游戏仓库。后续合入以用户导出的审阅结果为准。

## 复现

安装 Git LFS，克隆后运行 `git lfs install`、`git lfs pull`，使用 Godot 4.7.2 导入 `project.godot`。运行时台词播放不请求外部 API。

验证脚本：`warden_dialogue_test.gd`（50）、`crown_intro_test.gd`（44）、`player_input_v11_test.gd`（19）、`post_victory_movement_test.gd`（21）、`ground_audio_update_test.gd`（43），均位于 `tests/`，合计 177 项。

Web 构建仍按仓库既有规则排除。可用现有 Web preset 自行导出。当前本地正式构建为 `voice-victor-20260929`，固定入口 `index-voice-victor.html`；查询参数只标记链接，不切换服务器上的版本。

不上传本地凭据、缓存、虚拟环境、QA 备份录像或旧的服务端签名下载记录。资产继续由 Git LFS 管理。
