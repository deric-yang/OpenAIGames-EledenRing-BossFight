# 冠冕过场与战斗衔接更新 · 2026-09-28

本轮保留 V09 战斗与「冠冕归沙」过场，修改三个玩家可见行为。

## 从跪姿候场到起身开战

- 出生、重置与沿沙丘接近时，王骸的守望者始终保持与过场第一镜相同的捧冠跪姿。旗枪竖在身旁，冠冕完整；候场不运行溶解计时，也不渲染沙粒实例。
- 进入触发距离后，沿用同一个冠冕、手部姿势和场景位置开始过场。不会先站立再突然跪下，也不再瞬间转向接近的玩家。
- 自然结束和长按 ESC 跳过仍共用黑场恢复流程。恢复游戏镜头和淡入时 Boss 继续跪着；淡入结束进入战斗后播放 `Warden_Rise`，起身完成才交给进攻状态机。
- 保留 B / P 和动作看板的调试能力：主动绕过过场进入战斗或审阅时清理冠冕布景、恢复手持旗枪。

## 战斗音乐

- 用户提供的原文件：`/Users/yangjianwen/Music/网易云音乐/齋藤司 - The Final Battle.ncm`，原文件未修改。
- 运行时资产：`assets/runtime/audio/v10/final_battle.ogg`，44.1 kHz 双声道、约 298.45 秒、约 4.8 MiB。
- 本地 NCM 解码使用 [pyNCMDUMP](https://github.com/allenfrostline/pyNCMDUMP)，依据 [ncmdump 的封面块读取实现](https://github.com/taurusxin/ncmdump/blob/main/src/ncmcrypt.cpp) 修正封面预留空间的跳过处理。转换工具与中间 MP3 只保留在临时目录；没有上传原音乐。
- FFmpeg 对解码后的全长音频及最终 OGG 均完成完整解码。源曲测得 -10.19 LUFS，旧 BGM 为 -23.08 LUFS；新曲固定衰减 12.89 dB，最终 OGG 测得 -23.14 LUFS、真峰值 -12.04 dBTP，保留 16 LU 的原曲动态。首尾各加极短淡入/淡出避免边界点击声，没有裁掉段落。
- 游戏内继续使用原有 -3 dB 播放器增益与战斗淡入淡出。只在战斗中循环；候场、过场、战败/胜利后退出战斗及重置时停止。浏览器首次播放仍需要一次按键或点击手势。

## SFX039 裂地声与候场低频氛围

- `BROKEN - CK - STONE Rock Drop On Rocks Large A 01`：仅取 0–1.42 秒；02：仅取 0–1.58 秒。两个原文件的下一次独立撞击均在约 3.05 秒开始，不会混入。转为 44.1 kHz / 单声道 / PCM16 WAV，微淡出避免截断声。
- 每次真正出现岩石裂地时随机选一个版本。当前覆盖 `fissure` / `eruption` 的四个招式；组合下砸每个独立砸地分别触发。前戳等待 0.85 秒预警后，跟随裂地爆发播放一次，后续逐帧推进的判定不重复触发。推开、怒吼和仅扬沙的扫击不叠加落石声。
- `BROKEN - DESIGNED - EARTHQUAKE Rumble LFE 02` 替换开战前的环境音乐，应用 1.3 倍线性音量（约 +2.28 dB），增加 -1 dBFS 峰值限制防削波。原曲首尾做 3 秒等功率交叉渐变，生成 56.56 秒循环；最终 OGG 测得 -10.43 dBFS RMS，采样峰值 -0.74 dBFS。
- 候场、接近和过场期间播放低频氛围；正式战斗淡出低频、淡入《The Final Battle》。战败/胜利不重新开启候场声，R 复活后恢复。首次音频仍由浏览器交互手势解锁。
- 可用 `tools/audio/prepare_sfx039.py --ffmpeg <本地路径>` 重建，来源与裁切记录见 `assets/runtime/audio/v10/sfx039-provenance.json`。共享音效库原文件保持不变。
