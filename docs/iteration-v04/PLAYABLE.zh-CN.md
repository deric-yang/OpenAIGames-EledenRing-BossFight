# V04 可玩切片与完整场景

## 打开

- 浏览器：http://127.0.0.1:8093/ 。本地服务只开放 `builds/web`；服务未运行时双击 `启动Web预览.command`。
- 原生：双击项目内 `启动游戏.command`。
- 无 AI 自由巡览：`启动场景装配.command` 或 http://127.0.0.1:8093/?assembly=1 。旧版静态拼装保留在 `?assembly-v03=1`。
- 资产与动作审阅：http://127.0.0.1:8093/asset-review/ 。选择角色后可切换已烘焙动作。
- 完整 Blender：`assets/processed/battlefield_v04/weeping-dunes-v04.blend`；也可双击 `打开Blender完整场景.command`。

## 操作

| 按键 | 行为 |
|---|---|
| WASD / Shift | 移动 / 疾跑 |
| 鼠标左键或 J | 普攻；攻击中再次输入可接下一段 |
| 空格 | 翻滚；被掀翻后受身起立 |
| Tab / 鼠标右键拖动 | 切换锁定 / 调整镜头 |
| F | Boss 出现硬直机会时，靠近处决 |
| R | 从黄金符文重新开始 |
| P | 暂停 Boss AI、自由查看场景；再按恢复战斗 |
| B | 逐一预览所选 Boss 动作；P 返回战斗 |

启动后角色以金色粒子凝聚，地点名居中出现；凝聚结束后，首次移动或攻击才进入战斗。当前已有临时生命与耐力数值，便于验证受击、处决、死亡、击败和重生闭环，尚未做难度平衡。

## 资产与空间

玩家约 1.85 米，银灰雕纹甲、灰黑披风、羽饰与直剑；老将约 6.4 米，旧金铠甲、酒红战袍、羽饰大氅与战旗长枪。旧巨剑方案保留在历史目录，但不用于 V04 战斗。

Tripo 新增玩家、老将、直剑、枪体、断弓和阵亡士兵，角色通过 rig-check 后生成 Mixamo 命名骨架。玩家 31,999 / Boss 55,000 三角面、2K 材质，减面后没有未绑定顶点；直剑 6,500 / 枪体 9,500 三角面。两人各增加 12 节披风骨骼，战旗有独立的 7 节骨骼。保留生成原件、优化 `.blend` 和运行时 GLB。

战场 320 × 360 米，中央也有连续起伏和对应碰撞。世界坐标多尺度噪声混合沙地颜色，风纹局部出现并按距离衰减。保留已认可的黄金树，魂幡底部接地；散布断弓、士兵遗骸、剑戟、箭杆、盾牌、头盔、断刃和甲片。火堆、复活符文与暖色发光点已经接入。

Blender 场景按地形、残骸、魂幡、角色、火源和灯光分组，静态资产采用可移动的集合实例。移动整名角色请选择 `Knight_MOVE_THIS` 或 `General_MOVE_THIS`。角色保留蒙皮、动画和同步 `WeaponGrip` 轨道；骨架和武器挂点必须切换到同一个动作。文件内 `Switch_Selected_Motion.py` 提供成对切换助手，可在文本编辑器运行后使用 Python Console 调用 `set_motion('general', '动作 ID')`。动作名称和 ID 对照见 `selected-motions.json`。

## 动作、特效和声音

本次保留共享看板全部 38 条选择：37 条 keep，以及虽然仍标 pending、但写了明确怒吼用途的那一条。没有修改原始评审状态。37 条用于 Boss，另 1 条用于玩家处决。加上 Sekiro 玩家动作和通用待机，最终玩家 12 个、Boss 38 个烘焙片段。UE / UAL / Mixamo 做骨语义、参考姿势、骨长与髋高度转换，30 fps 烘焙到实际目标角色，移除水平根运动，由控制器负责位移。

已接入三连、翻滚、受击、击飞、倒地受身、死亡和处决；Boss 包含接近、侧移、后撤、攻击组合、反击、硬直、起身怒吼，以及 Slash4 → Slash8 衔接。B 可逐一检查所有所选 Boss 动作。

特效仅采用用户指定的 Blood Burst、Blood Splash 与 NS Basic SKM。Burst 出现在命中部位，Splash 延后落到实际沙丘高度，强度按伤害分级。SKM 复制实际角色、从当前蒙皮姿势采样粒子；玩家金色凝聚，Boss 灰色消散。这里使用的是 VFX Lab 已转换的 Godot 重建版本，不宣称与原 Niagara 完全一致。

23 个指定声音组成 18 类事件，完整来源和名称在 `assets/runtime/audio/v04/manifest.json`。包括双方脚步、玩家沙地摩擦循环、翻滚、环境底噪、三段挥剑、Boss 挥枪、受击、怒吼、处决双层声音、死亡和胜利嘲笑。挥空也播放挥舞音；只有实际伤害命中才播放血液声和血液特效。怒吼击退不产生血液。

## 本版边界

- Web 使用 Compatibility 渲染器：薄雾、层叠雾片与柔和光束近似体积感，不是 Forward+ 原生体积雾。
- 披风与战旗使用骨骼风动、惯性和垂落方向近似，尚无完整布料碰撞；极端动作仍可能局部穿插。
- 自动绑定没有独立手指骨骼；目前武器随手部挂点运动，后续可人工精修握指及双手支撑。
- 攻击窗口和范围是首轮可玩配置，尚未逐招完成武器轨迹校准；攻击根运动已转换为原地动作，数值、攻击节奏和镜头仍可继续调优。
- 目前重点是桌面浏览器和本机原生运行；未做移动端适配或跨设备性能保证。

## 复现与验证

`tests/playable_v04_regression.gd` 检查全部烘焙动作及命中/挥空/翻滚/处决/死亡/重开，结果写入 `qa/playable-v04/regression.json`。`tests/playable_v04_review.gd` 输出实机关键帧及 Blender 使用的场景摆放记录。UI 原有时序检查在 `tests/ui_review.gd`。

已通过 70 项可玩回归、15 项 UI 检查和 8 项 Tripo 管线测试。原生实际渲染验证出生、对峙、怒吼、挥剑、血液、消散和奖励；Blender 打开重渲染成功。浏览器验证了移动、两段以上挥舞、翻滚、Boss 接近与攻击、玩家死亡/重开，以及玩家实际命中使 Boss 从 680 降至 649，并显示虚血。审阅页验证玩家 12 个和 Boss 38 个动作选项。

绘制优化后，同一出生视角从约 408 次绘制 / 150 万三角面降为 165 次 / 73 万。此次共享开发机器上的浏览器单点采样：出生视角约 31–33 FPS、普通交战一次采样 42 FPS；血液批处理优化前，命中时一次采样为 24 FPS。记录在 `qa/playable-v04/browser-validation.json`，不作为隔离性能基准或跨设备保证。地面血迹随后合并为 MultiMesh，并移除了 Burst 中不可见的地面血迹绘制。

首次使用血液效果曾出现单次 1 FPS 卡顿采样，随后增加了出生阶段的不可见材质预热。预热后的浏览器验证中，两次命中正常扣血、血液声正常、无控制台错误；当时较小的侧栏视口采样为 54 FPS / 149 次绘制。侧栏视口与前述 1280×720 不同，因此这不是可直接比较的性能提升比例，仍需后续统一设备、分辨率和负载做完整基准。

管线依次为 `prepare_characters_v04.py` → Godot 导入 → `bake_character_motions.gd` → 实机 QA → `assemble_blender_v04.py` → `review_blender_v04.py`。材质导出兼容修正由 `glb_material_tint.py` 保存标准 glTF 色因子。`finalize_knight_material.gd` 可更新已烘焙版本的披风色因子。

新概念图与参考：`docs/concepts/v04`、`docs/iteration-v04/references`。生成任务、提示词与服务返回保存在 `scripts/tripo/production-v01.json` 和 `generation-records/production-v01`；不包含在 Web 构建中。本轮任务记录消耗合计 390 credits。
