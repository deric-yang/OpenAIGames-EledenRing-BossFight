# 《恸哭沙丘》垂直切片 GDD

## 体验支柱

1. **沙丘尺度**：宽阔战场、远置空气墙和深度雾共同制造远方仍在延伸的空间感。
2. **远景奇观**：衰败黑树、树体金色裂隙和天边帷幔形成第一眼可识别的视觉锚点。
3. **战场质感**：沙土、破碎遗迹、金属残骸、旗帜、火炬和尘雾通过材质、灯光和脚步反馈形成层次。
4. **体型压迫**：Boss 当前只用体块占位，但镜头、玩家比例、攻击覆盖和仰角构图必须先证明未来大型 Boss 可读。
5. **克制 UI**：暗红、旧金和羊皮纸色构成原创的魂系 HUD；地点提示固定为右下角“恸哭沙丘”。

## 当前阶段

本阶段只完成场地、UI、镜头构图、资产生产管线和 Web 渲染样板。Boss 正式模型、技能模组、AI 决策、动作迁移和骨骼重定向延后。

## 场地构图

- **近景**：沙土、断裂石板、半埋遗迹、战争遗骸、折断武器、焦黑旗帜、火炬和低密度烟尘。
- **中景**：约 28–32m × 20–24m 的战斗核心，保留玩家和 Boss 的移动、攻击与镜头空间；外层视觉地形延伸到约 64–72m × 48–56m。
- **远景**：巨大衰败黑树，树体裂隙发出受控金光；黑树后方垂下半透明帷幔，地平线由沙丘、残墙和雾化空气墙收束。
- **空气墙**：放在远处，通过沙丘、遗迹和深度/高度雾隐藏，不在默认镜头中显示硬边。

## UI 方向

- 玩家血条在左上角，保留当前 HP 与延迟虚血的显示层级。
- Boss 血条在屏幕底部居中，阶段只改变状态文字、颜色和装饰强度。
- 地点提示在右下偏中区域显示：主标题为“恸哭沙丘”，副标题使用原创状态文字，淡入、停留和缓慢渐隐。
- UI 只使用程序绘制或已登记授权的字体/纹理，不复制《血源诅咒》等作品的具体素材。

## 镜头方向

- 自由视角保持玩家中心、适度可调的镜头高度和远景可见性。
- Tab 切换锁定敌人；锁定目标使用动态关注点，不直接看 Boss 根节点。
- Boss 体型显著增大时允许自然仰角，同时保证玩家、Boss 轮廓、武器轨迹和脚下接触关系可读。
- 锁定/解除锁定、演出、冲击、FOV 和震动都需要平滑恢复，不能把镜头锁死在旧场景参数。

## 流程基线

`INTRO → PHASE_1 → PHASE_TRANSITION → PHASE_2 → EXECUTION / DEFEAT → RESET`

流程代码当前作为场地和 UI 的白盒验证工具保留；本阶段不重做 Boss 战斗规则。

## 技术基线

Godot 4.7.2、GL Compatibility、WebGL 2.0、1280×720、60 Hz 物理。运行时以 StandardMaterial3D 为主，配合 LightmapGI、SSAO、ReflectionProbe、深度/高度雾和有限 Glow；不把 Forward+ 特性作为 Web 依赖。
