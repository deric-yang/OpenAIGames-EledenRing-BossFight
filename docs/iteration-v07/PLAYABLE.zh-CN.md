# V07：持握、披风与战斗反馈修订

试玩：http://127.0.0.1:8093/ 。操作沿用 WASD / Shift / 左键轻攻击 / 右键突刺 / Space 翻滚 / F 处决 / R 重开。

- 恢复完整 32k 三角面玩家模型，撤掉 V06 补背甲；没有删除披风网格。重新绑定披风后侧及侧缘，保护四肢盔甲权重；肩部固定，下摆按重力悬垂，跟随躯干朝向并带小幅阻尼风动。生成模型没有独立手指骨，右手握指在绑定网格中做了收拢。
- 剑柄使用真实几何中心 `(0.001, 0.22, 0.169)` 校准，而非只移动 Y 轴。固定掌心挂点跟随最终混合后的右手骨；重突刺转动手和武器一起完成，不再独立把武器指向前方。
- 双方共用命中冻结计时器：轻攻击 8/60 秒，重攻击、处决 10/60 秒，Boss 命中 6/60 秒。动作、位移、武器、旗布和武器拖尾一起暂停，摄像机、声音、UI 继续运行。命中回调在双方本帧动作更新完成后集中处理，避免一方先解冻。连击输入可在顿帧中缓存。
- 反击推掌 Anim_DSS3_Combo_B1_RM 伤害为 0，只保留一次打断窗口；它和怒吼都使用 Sekiro 的站立 `Hit_Chest` 反馈、地面击退和自动恢复，不进入 launch/down。原本会击飞的重伤害招式继续保留倒地。
- Boss 行进/疾跑速度调整为 4.6 / 8.4 米每秒；动画步频按体型后的步幅匹配，横移/后退单独匹配步频；玩家慢跑按 4.3 米每秒基准匹配。移动中更新速率，解决同一片段由慢走切疾跑时不更新的问题。
- 14 个普通攻击招式中 6 个在起手时播放 troll_monster_battle_grunt_01 / 03；不在每段 combo 命中时重复播放。脚步继续静音；单次死亡掉剑、播报和循环 BGM 保留。
- Boss 起手 50ms 轻震，普通命中 75ms、重击 130ms、玩家处决 150ms。采用镜头位移与衰减，最后恢复到零偏移，不再用长时间旋转晃动。
- 特效参考 ThreeJSVFX-Demo 的 IceAbility / MeteorAbility / GroundFissures，重写成 Godot 实例化碎石、掀起地块、程序化尘雾、火星、贴合沙丘的裂缝。前戳裂隙在 320ms 内向前推进，判定跟随前沿且每次波浪只命中一次；下砸以放射式地块和尘土爆裂表现。每次攻击使用三个粒子实例批次，最多保留八组效果。来源与许可证见 THIRD-PARTY-NOTICES.md。

## 表现边界

披风是低成本骨骼跟随，不是完整自碰撞布料模拟；极端翻滚、贴身战斗仍可能出现局部布料与腿甲穿插。程序化砂石特效已经替换旧版大块软贴片，但仍是浏览器预算内的一版实现，需要继续根据实机审阅调整密度、速度和材质。

网页验收：2026-09-28，IAB/WebGL，出生点视角约 30 FPS / 149–162 draw calls；轻攻击和重突刺输入已验，控制台无错误。该数值不代表所有战斗场景的性能下限。
