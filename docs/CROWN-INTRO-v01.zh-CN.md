# 冠冕归沙 · 实时过场 v01

2026-09-28。根据已确认的四格分镜制作。化沙主体是 Boss 手中的冠冕，Boss 本体始终保留。采用当前老将模型、现有沙丘战场和 Godot Compatibility 渲染。

## 立即审阅

- 浏览器：<http://127.0.0.1:8096/?crown-intro=1>。自动播放一遍；结束后按 **R** 重播，按 **P** 进入战斗。审阅模式结束后 Boss 不主动攻击。
- 原生：双击项目根目录 `启动冠冕过场.command`，或 `启动游戏.command` 正常游玩。
- 正常流程：玩家从复活点出发，接近 Boss 至 14 米内且高度接近时播放；自然结束或跳过都进入战斗。重置遭遇会重新允许播放。
- **按住 ESC 0.8 秒跳过**，松开取消；跳过用 0.3 秒淡黑。过场失焦暂停，并清除长按进度。

Web 构建保存在 `builds/crown-intro-v01`，独立服务端口 8096。未覆盖主线程原有 `builds/web` / 8093 构建。若服务停止，可执行：

```sh
python3 -m http.server 8096 --bind 127.0.0.1 --directory builds/crown-intro-v01
```

## 已实现

| 时间 | 实际内容 |
| --- | --- |
| 0–2 秒 | 双手和冠冕近景，短淡入、缓推；冠冕底缘开始化沙 |
| 2–5 秒 | 老将胸像，冠冕逐渐消失；表面沙粒向下倾泻 |
| 5–8.4 秒 | 跪地中景，冠冕完全消失后保留空手停顿，轻微抬头 |
| 8.4–10 秒 | 战场、巨树和 Boss 广角；8.8 秒开始平滑淡黑 |

黑场内恢复角色、武器与战斗相机，再用 0.45 秒淡入战斗。这段交接不属于四镜头的 10 秒本体。

- 跪姿复用 `Warden_Kneel_Hold` 的下肢和骨盆。原处决姿势过度俯身，过场单独恢复较直立的上身，再用双臂 IK 托冠，不改原动作文件。
- 新建独立树枝冠冕：三道环带、十二组枝叶和弧形纹饰，附旧金属与粉化材质。它是本地程序建模资产，本轮没有调用 Tripo 或消耗生成额度。
- 冠冕三角面按面积采样 22,000 个预置粒子出生点；同一方向加噪声时间场驱动材质消失和沙粒释放。22,000 是全段总数，不是同时存活量。
- 沙粒出生时固定世界变换，采用世界向下重力、少量侧风、触地滑动与缩小退出。使用 MultiMesh 和 spatial shader，未使用 Compatibility 不支持的 `emit_particle()`。
- 过场内藏起玩家、战斗 HUD 和手持长枪，旁置一把长枪；加入局部暖光、轻微暗角和颜色处理。结尾恢复战斗眼部红光。
- 玩家运动、伤害、耐力、Boss AI 和战斗计时在过场及淡入完成前均被隔离。正常结束与跳过调用相同幂等交接路径。
- 当前流沙声音暂用现有细碎摩擦循环，跟随消散强度淡入淡出；正式沙流 Foley 尚待单独审阅。Web 音频需首次键鼠交互后才可播放。

## 验证

- `tests/crown_intro_test.gd`：25 项通过，覆盖镜头边界、双手到达挂点、玩法冻结、自然结束、短按取消、长按跳过、全黑交接、失焦清理、重置、真实接近触发与恢复战斗、动作看板隔离。
- `tests/iteration_v09_core.gd`：现有战斗回归 152 项通过。
- `tests/crown_intro_review.gd`：使用真实场景和 Compatibility 渲染，保存六张关键帧到 `qa/crown-intro-v01/`；检查后修正了俯身遮冠和近景构图。
- Web 导出成功，并在 Codex 内置浏览器实际打开；已观察真实冠冕首镜头、自然交接、审阅静止状态及 R 重播，检查时控制台无错误或警告。长按阈值通过 Godot 输入事件自动检查；尚未逐一实测不同浏览器的实体键长按、退出全屏或鼠标锁定行为。
- 本机内置浏览器一次完整播放测得平均 **29.36 FPS**，四镜头加交接约 **10.59 秒**；仅为本机这次采样，不代表其他设备或稳定帧率承诺。记录见 `qa/crown-intro-v01/web-smoke.json`。跳过提示使用已有拉丁字体，避免 Web 中文子集字体缺字。

这是一版可运行、可审阅的实时过场。当前美术来自实装游戏资产，并不等同于 AI 分镜图的离线画质；冠冕造型、手指贴合、沙流细尘层次和声音仍可继续美术打磨。Web 构建包含完整战场，初次需加载约 200 MB PCK 与 38 MB WASM，尚未做过场专用资源裁剪或移动端性能验收。

## 文件边界

- `scripts/cinematic/crown_intro.gd`：镜头、姿势、状态隔离、跳过和交接。
- `scripts/cinematic/crown_prop.gd`：原创冠冕网格、面积采样及粒子初始化。
- `shaders/cinematic/`：金属粉化、沙粒轨迹、过场颜色处理。
- `scripts/battle/playable_encounter.gd`：少量接入点；保留原有战斗实现。
- `qa/crown-intro-v01/playable_encounter.before.gd.txt`：本轮接入前快照，仅用于核对本轮修改。

技术原则参考此前分镜研究中的 [GDC 2019 Disintegrating Meshes](https://media.gdcvault.com/gdc2019/presentations/Renard_Rupert_Disintegrating_Meshes.pdf)。当前代码为本地新写实现，未复制第三方着色器或插件代码。
