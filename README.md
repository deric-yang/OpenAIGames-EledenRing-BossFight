本仓库收录沙丘 Boss 战「古战场遗迹」的 Godot 工程源码、场景定义、Shader、工具、测试与开发文档。详见 [中文项目说明](README.zh-CN.md)。

### 资产依赖

此次为源码提交，不包含 `assets/` 下模型、动画、贴图和音频，也不包含 `builds/`、`qa/`、`.godot/`、生成任务记录或本地凭据。单独克隆本仓库不能直接运行完整游戏；需要从原始项目补齐同路径资产，并使用项目对应的 Godot 版本导入。开发文档中的本地路径和验证记录保留原始上下文，不代表克隆后已经执行测试。
